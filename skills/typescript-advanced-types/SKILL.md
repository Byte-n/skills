# TypeScript 高级类型

本技能赋予智能体处理极高复杂度 TypeScript 类型逻辑的能力。它不仅涵盖基础语法，更侧重于解决工程实践中的类型体操（Type Challenges）与契约式编程。

## 何时激活此技能

- 设计类型安全代码，创建高复用性的泛型组件与接口（如 interface Response<T> { data: T }）。
- 通过 extends 实现泛型约束，或利用 extends / & 实现灵活的类型复用。
- 利用条件类型（Conditional Types）与 infer 关键字，实现深层嵌套的自动类型推导。
- 通过类型守卫（Type Guards）实现精准的静态类型推导（如 input is string）。
- 使用 as const 定义常量字面量类型，或利用 satisfies 进行不丢失原始信息的类型检查。
- 进行复杂的类型转换，或在必要场景下使用类型断言引导推导方向。
- 优化 TypeScript 的自动推导机制，减少手动声明压力。

## 核心逻辑架构

### 1. 泛型与推断控制 (Generics & Inference)

除了基础泛型，重点在于**推断锁定**。

- **NoInfer<T>**: 防止参数推断导致的类型并集扩大，强制契约一致性。
- **泛型约束**: 使用 `extends` 限制类型范围。

### 2. 类型变换逻辑 (Type Transformation)

- **条件类型**: `T extends U ? X : Y` 及其配合 `infer` 的深层提取。
- **映射类型**: 利用 `as` 进行键名重映射（Key Remapping）和过滤。
- **模板字面量**: 字符串类型的模式匹配与自动生成。

### 3. 类型守卫与断言 (Narrowing & Assertions)

- **类型守卫**: `value is Type` 实现精准收窄。
- **断言函数**: `asserts value is Type` 用于流程控制。
- **const 断言**: `as const` 锁定字面量。

## 常见陷阱

- **过度使用 `any`**：违背了 TypeScript 的初衷。
- **过于复杂的类型**：可能减慢编译速度。
- **未使用可辨识联合类型**：错过类型收窄的机会。
- **循环类型引用**：可能导致编译器错误。

## 性能注意事项

- 避免使用深度嵌套的条件类型。
- 尽可能使用简单的类型。
- 限制递归类型中的递归深度。

## 最佳实践

- **优先使用 `unknown` 而非 `any`**：强制执行类型检查。
- **对象定义优先使用 `interface`**：获得更好的错误提示。
- **联合类型和复杂类型使用 `type`**：更具灵活性。
- **善用类型推断**：在可能的情况下让 TypeScript 自动推断。
- **创建辅助类型**：构建可复用的类型工具。
- **使用 const 断言**：保留字面量类型。
- **避免类型断言 (as)**：优先使用类型守卫。
- **记录复杂类型**：添加 JSDoc 注释。
